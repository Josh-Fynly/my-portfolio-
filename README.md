## ⚡ Quick Start

### Local Development
```bash
git clone https://github.com/Josh-Fynly/my-portfolio.git
cd my-portfolio
npm ci
npm run dev
```
Open [http://localhost:3000](http://localhost:3000)

### Production Build
```bash
npm run build
npm start
```

### Deployment
Push to the `main` branch. Vercel handles automated preview and production deployments.

## 🏗️ Engineering Practices
This repository enforces discipline over convenience:

- **Code Quality:** Strict TypeScript, ESLint, and Prettier. No `any` types without explicit justification.
- **Performance:** Responsive design using CSS `clamp()`. Next.js static generation where applicable. Target Lighthouse score: 90+.
- **Security:** Strict Content Security Policy (CSP) headers, sanitized form inputs, and zero hardcoded secrets.
- **Accessibility:** Semantic HTML, WCAG 2.1 Level AA color contrast (4.5:1+), and full keyboard navigation support.
- **Maintainability:** Centralized project data arrays for easy scaling. No fragmented patch snippets; complete, dependency-ordered file structures.

## 🔄 Development Workflow
1. **Branch:** `git checkout -b feature/your-feature-name`
2. **Develop:** `npm run dev` (iterate with hot reloading)
3. **Verify:** `npm run build` (ensure no TypeScript or build errors)
4. **Commit:** `git commit -m "feat: concise description of change"`
5. **Push & PR:** `git push origin feature/your-feature-name` → Merge to `main`
6. **Deploy:** Vercel automatically promotes to production.
